Instalar no telemóvel

No Android, abre esta página no Google Chrome, toca no menu ⋮ e escolhe “Instalar aplicação” ou “Adicionar ao ecrã principal”.

A instalação requer HTTPS e que o Chrome reconheça o manifesto e o service worker.

Sincronização entre os dois telemóveis

A sincronização usa uma conta de cada pessoa e uma base de dados privada partilhada. Os dados continuam guardados neste telemóvel e são enviados apenas quando existe ligação à internet.

Ainda não configurada. Segue o guia incluído no ZIP para criar o projeto de sincronização.

Cada adulto pode usar a sua própria conta. Se o Supabase pedir confirmação, confirma o email antes de iniciar sessão.

A aplicação verifica alterações enquanto está aberta (aproximadamente a cada 30 segundos). Se os dois telemóveis alterarem os dados ao mesmo tempo, não substitui alterações silenciosamente: apresenta um conflito para escolherem que versão manter.

Cópias de segurança e privacidade

Sem configurar a sincronização, os dados ficam apenas no armazenamento local deste navegador. Com a sincronização ativada, são enviados para o projeto Supabase que o casal configurar, protegidos por autenticação e regras de acesso.

Instalação offline

Publique os ficheiros num alojamento HTTPS, abra o site uma vez com internet e escolha “Adicionar ao ecrã principal” ou “Instalar aplicação”. Depois da primeira abertura, pode funcionar offline.
