Definição dos ciclos financeiros

Entradas de rendimento marcadas como definidoras de ciclo separadas por até este número de dias são agrupadas no mesmo recebimento conjunto. O ciclo inicia no primeiro vencimento do grupo e fecha antes do próximo recebimento.

Aceder à DuoFin

Não precisas de instalar a DuoFin. Abre o mesmo endereço HTTPS no navegador do Windows, iPhone ou Android e inicia sessão. Os dados partilhados são carregados do projeto Supabase configurado.

Windows (Edge ou Chrome)

  1. Abre o endereço HTTPS da DuoFin no navegador.
  2. Inicia sessão com a conta associada ao orçamento.
  3. Opcional: no menu do navegador escolhe «Instalar este site como uma aplicação» para teres um ícone e uma janela própria.

Android (Chrome)

  1. Abre o mesmo endereço no Chrome.
  2. Inicia sessão com a conta associada ao orçamento.
  3. Opcional: usa «Instalar aplicação» ou «Adicionar ao ecrã principal» no menu do navegador.

iPhone (Safari)

  1. Abre o mesmo endereço diretamente no Safari.
  2. Inicia sessão com a conta associada ao orçamento.
  3. Já podes utilizar a DuoFin. Opcionalmente, usa «Partilhar» e «Adicionar ao ecrã principal» para criar um ícone.

A instalação é opcional. Se o navegador não apresentar a opção, continua a utilizar a DuoFin normalmente nesta página.

Sincronização entre os dispositivos

A sincronização usa uma conta de cada pessoa e uma base de dados privada partilhada. Inclui fusão automática de movimentos criados em simultâneo nos dois dispositivos.

Ainda não configurada. Segue o guia incluído no ZIP para criar o projeto de sincronização.

Cada adulto pode usar a sua própria conta. Se o Supabase pedir confirmação, confirma o email antes de iniciar sessão.

A aplicação verifica alterações enquanto está aberta (aproximadamente a cada 15 segundos). Novos movimentos e regras criados nos dois dispositivos são fundidos automaticamente.

Cópias de segurança e privacidade

Sem configurar a sincronização, os dados ficam apenas no armazenamento local deste navegador. Com a sincronização ativada, são enviados para o projeto Supabase que o casal configurar, protegidos por autenticação e regras de acesso.
